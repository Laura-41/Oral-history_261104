- `entities.csv`：跨文档共享的实体总表；

- `time_expressions.csv`：全部原文中的明确年月日及其规范值、字符偏移和来源；录音时间戳不进入本表；

## 四 人工确认的最低标准

- 每个一级事件都有事件名称、六类事件之一、核心过程、参与者、环境和原文证据；
- 只有确实需要展开的长事件才建立二级阶段；
- 一级事件之间只建立历史时间顺承的 `NEXT`；
- 采访者提问、编校注释、时间码和无关信息仍保存在原文层；
- 每一条原文片段至少挂接事件、阶段或文档中的一个；
- `coverage_rate` 必须保持为 `1.0000`。
- 每个实体提及的 `start_offset/end_offset` 必须精确返回原文；
- 同一实体跨文档使用同一 `entity_id`；
- 人物小传、脚注和采访者提问中的实体不能冒充受访者事件论元；
- 每个一级事件都有 `EventTime`，不确定时间必须显式记录精度和确定性；
- 每条全文日期提及进入 `TimeExpression`，并保留原文偏移和来源；录音时间戳不得误作历史时间；
- `review_status` 表示是否人工核验，`authority_status` 表示现实指称是否能够规范确定，二者不得混用；
- 各人物只保留自己的 `NEXT` 链，综合时间轴由规范时间动态生成。
